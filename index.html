      รายการที่จะพิมพ์

        บาร์โค้ดพนักงานชั่วคราว (Part-Time)

        พิมพ์ชื่อ + ใส่เลขบัตรประชาชน 13 หลัก แล้วทำเป็นบาร์โค้ด — บนบัตรโชว์แค่ 4 ตัวท้าย สแกนบาร์โค้ดนี้ที่ไหนก็ได้ ชื่อนี้จะเป็นผู้จัด (ไม่แตะรายชื่อพนักงานประจำ)
          กดที่ใบตัวอย่าง ก็สั่งพิมพ์ได้เลย

          ใครเป็นผู้จัด?
          Update Data

          กอัปเดตจากไฟล์

          อ่านคอลัมน์ ชื่อ / Name และ เลขพนักงาน / รหัสพนักงาน / Employee ID ให้เอง (ถ้ามีคอลัมน์ นามสกุล / Last name จะรวมให้) ถ้าไฟล์ไม่มีหัวตารางจะเดาจากเนื้อหา

          ไฟล์ PDF และรูปภาพ (JPG / PNG): อ่านตัวหนังสือในเครื่องคุณเอง ไม่อัปโหลดไฟล์ไปไหน — ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอ่าน ภาพเบลอหรือลายมืออาจอ่านผิด จึงตรวจชื่อและรหัสในตัวอย่างก่อนกดนำเข้าเสมอ

          ขรายชื่อปัจจุบัน

          เพิ่ม / แก้ทีละคน
          เติมเลข 8 หลักให้รายชื่อเดิม

          คัดลอกคอลัมน์เลขพนักงาน 8 หลักจาก Excel มาวางได้เลย (ไม่ต้องมีชื่อ วางทั้งคอลัมน์ได้) — ระบบจับคู่กับรายชื่อจาก 4 ตัวท้าย แล้วโชว์เลข 8 หลักในรายชื่อและพิมพ์บนบัตร ส่วนการสแกนและการค้นหาด้วย 4 ตัวท้ายยังใช้เหมือนเดิม

          รหัสชื่อชื่อเล่นตารางเวลางาน
          ยังไม่มีรายชื่อ

          กอัปเดตจากไฟล์

          รองรับ 2 แบบ: แถวละพื้นที่ (มีคอลัมน์ Trip / เส้นทาง และคอลัมน์พื้นที่ เช่น เขต แขวง อำเภอ ตำบล จังหวัด รหัสไปรษณีย์) หรือหัวคอลัมน์เป็นชื่อ Trip แล้วรายชื่อพื้นที่เรียงลงมาใต้หัว — ใบปะหน้าจะใส่ Trip ให้ตามที่อยู่ของแต่ละออเดอร์ (ต้องนำเข้าไฟล์ Call Center ที่มีคอลัมน์ที่อยู่ในกล่องเขียว)

          ขเส้นทางปัจจุบัน

          พื้นที่Trip
          ยังไม่มีเส้นทาง

          คตรวจโซน Trip 1-20 กับออเดอร์จริง อ่านอย่างเดียว

          ไม่ต้องนำไฟล์เข้า — โปรแกรมอ่านออเดอร์จากชีตที่เชื่อมต่อไว้เอง แล้วตรวจโซน Trip 1-20 ให้อัตโนมัติ: เปิดแท็บนี้ · ทุก 10 นาที · และ ทุกครั้งที่คุณอัปเดตเส้นทาง Trip (ก) หรือแก้ตารางโซนด้านล่าง ดูว่าออเดอร์ไหนอยู่นอกโซน แล้วจัดให้อยู่ Trip ที่ขับไปถึงก่อน (เวลาขับจาก Google Maps / OpenStreetMap) และเรียนรู้ว่าถนน/ซอยไหนไป Trip ไหน — ผลเข้าตารางเส้นทางเอง (เส้นทางที่นำเข้าเองไม่ถูกทับ) ใบปะหน้าจะพิมพ์ Trip ตามแขวง · ไม่แก้ชีตหรือไฟล์ ข้อมูลอยู่ในเบราว์เซอร์นี้เท่านั้น

          อ่านชีตไม่ได้ (เช่นเปิดใน Artifact)? ใช้ไฟล์ออเดอร์แทน
          ตารางโซน Trip 1-20 (พิมพ์จากรูป — ตรวจและแก้ได้)

          1 บรรทัดต่อ 1 Trip: เลข Trip [Tab] โซน / โซน / โซน · ชื่อเรียกอื่นของโซนเดียวกันคั่นด้วย | · ชื่อในวงเล็บนับเป็นโซนเพิ่ม · ดี4 (รับหน้ากระจก) ไม่นำมาจับออเดอร์

          กลิงก์ Google Sheet อ่านอย่างเดียว

          โปรแกรมอ่านชีตอย่างเดียว ไม่แก้ ไม่ลบ ไม่เพิ่มอะไรในชีต — ส่งไปค้นหาเฉพาะเลขออเดอร์ที่สแกน แล้วเก็บผลไว้ในเบราว์เซอร์นี้. ใช้คอลัมน์ Order Number (เลขออเดอร์), Customer Name (ชื่อลูกค้า), Original Expected Date (วันที่), Original Expected Time (เวลา) และ Sub District (แขวง / เส้นถนน) — ค้นหาจากแท็บที่ลิงก์ชี้อยู่
