          กดที่ใบตัวอย่าง ก็สั่งพิมพ์ได้เลย

          โปรแกรมอ่านชีตอย่างเดียว ไม่แก้ ไม่ลบ ไม่เพิ่มอะไรในชีต — ส่งไปค้นหาเฉพาะเลขออเดอร์ที่สแกน แล้วเก็บผลไว้ในเบราว์เซอร์นี้. ใช้คอลัมน์ Order Number (เลขออเดอร์), Customer Name (ชื่อลูกค้า), Original Expected Date (วันที่), Original Expected Time (เวลา) และ Sub District (แขวง / เส้นถนน) — ค้นหาจากแท็บที่ลิงก์ชี้อยู่

          ขลิงก์ Google Sheet ที่ 2 ทำงานเองทันที

          ชีตที่ 2 — ใช้เมื่อเลขออเดอร์ที่สแกนไม่อยู่ในชีตช่อง ก (ชีตช่อง ก มาก่อนเสมอ แล้วจึงค้นชีตนี้ แล้วค้นไฟล์ Excel). อ่านอย่างเดียวเหมือนช่อง ก และใช้หัวคอลัมน์ชุดเดียวกัน: Order Number, Customer Name, Original Expected Date / Time, Sub District, District, Post Code, Shipping Address — ค้นหาจากแท็บที่ลิงก์ชี้อยู่

          คลิงก์ไฟล์ Excel / CSV ทำงานเองทันที

          แหล่งข้อมูลออเดอร์ที่ 2 — ใช้เมื่อเลขออเดอร์ที่สแกนไม่อยู่ในชีต (ชีตมาก่อนเสมอ). โปรแกรมโหลดไฟล์มาอ่านอย่างเดียว ไม่แก้ไฟล์ แล้วเก็บไว้ในหน่วยความจำของเบราว์เซอร์นี้ (อ่านใหม่ทุก 5 นาที และเมื่อเจอเลขออเดอร์ที่ยังไม่มี) ไม่ส่งเลขออเดอร์ไปที่ไหน. ต้องเป็นลิงก์ที่เปิดตัวไฟล์ได้ตรง ๆ (ลิงก์แชร์ของ OneDrive / SharePoint / Google Drive ธรรมดาอ่านไม่ได้) และไฟล์ต้องมีหัวคอลัมน์เหมือนชีต: Order Number, Customer Name, Original Expected Date / Time, Sub District, District, Post Code, Shipping Address
